# zipnative v0.1.0

Milestone **M1 — read + random access + secure extraction**. Tagged in git;
not published to npm (the first npm publication will occur at a later
version — versions identify code states, publication is distribution).

## Highlights

- `openZip()`: lazy central-directory reader with name-indexed random
  access — read one entry of a large archive without touching the rest.
- Secure-by-default `extractZip()`: zip-slip, symlink, duplicate-name and
  decompression-bomb guards, all CWE-tagged and caller-configurable.
- Zip64 reading with anti-spoofing cross-checks; ambiguous EOCD placement
  refused; overlapping entries rejected.

## Security

- Every untrusted-input loop is bounded by a named limit
  (`src/core/zip-limits.ts`), mirrored in SECURITY.md.
- Adversarial fuzzing suite built on an engine-independent raw byte-level
  archive builder (anti-circularity), including truncation/corruption
  rounds that assert clean typed errors — never hangs, never foreign
  exceptions.
