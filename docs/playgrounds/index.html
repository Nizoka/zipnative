Playgrounds

Every playground runs the real engine in your browser — a committed copy of zipnative's own zero-dependency dist/index.js, loaded locally (no CDN, no npm, nothing to install). What you see is exactly what the library does.

The browser path uses DecompressionStream/CompressionStream or the pure-TS tier — initNodeZipCodecs() is a Node-only optimisation and is never called here.
