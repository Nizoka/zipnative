# Support

- **Bug reports**: open a [GitHub issue](https://github.com/Nizoka/zipnative/issues)
  using the bug template. For parser bugs, attach the offending archive if it is
  shareable, or a script that generates an equivalent one (see the template).
- **Interop reports** (an archive zipnative wrote that another tool rejects, or
  vice versa): use the dedicated interop issue template and name the tool and
  its exact version.
- **Questions / ideas**: open a discussion or a feature-request issue.
- **Security vulnerabilities**: never a public issue — see [SECURITY.md](SECURITY.md).
